# Cabana Bela Sardenha — site

Site oficial da Cabana Bela Sardenha, cabana A-frame em Farroupilha, Serra Gaúcha (RS).
Publicado em https://cabanabelasardenha.com.br via GitHub Pages.

## Estrutura

- `index.html` — a página (gerada; não editar à mão).
- `img/` — fotos em WebP (640 px e 1200 px) e logos.
- `llms.txt` — resumo factual da cabana para assistentes de IA.
- `robots.txt`, `sitemap.xml`, `CNAME` — indexação e domínio.
- `_fonte/build.py` — gerador: textos, perguntas frequentes, avaliações e links ficam nele.
  Para alterar o site, edite `_fonte/build.py`, rode `python3 build.py` e copie a pasta `dist/` gerada para a raiz.

## Direitos

e não podem ser reutilizados sem autorização.
